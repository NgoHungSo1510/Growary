## Review Focus (5 Critical Failure Modes & Edge Cases)

1. **Race Condition khi quay Gacha & Mở Rương:** User nhấn liên tục có thể trừ coin/ticket trùng hoặc mở rương 2 lần. *Giải pháp:* Atomic MongoDB update (`$inc`, condition `balance >= cost`), optimistic locking/session check.
2. **Lệch múi giờ Event tuần & Cron Flash Sale:** Chênh lệch giữa server UTC và giờ Việt Nam (UTC+7) làm reset event sai giờ. *Giải pháp:* Sử dụng `getStartOfWeek` và cron timezone `Asia/Ho_Chi_Minh` đã chuẩn hóa.
3. **Drop frame & giật lag trên CS:GO Horizontal Reel:** Chạy danh sách animation card lớn trên máy yếu gây crash/lag. *Giải pháp:* `Animated.View` với `useNativeDriver: true`, card memoized bằng `React.memo`, cố định kích thước chiều rộng từng card.
4. **Xung đột tính giá Flash Sale + VIP Discount:** Làm tròn sai hoặc giảm giá quá 100%. *Giải pháp:* `finalPrice = Math.max(1, Math.ceil(pointCost * (1 - flashDiscount/100) * (1 - vipDiscount/100)))`.
5. **Safeguard các Event Type tương lai:** Client crash nếu server trả về event type chưa hỗ trợ (`double_cashback`, `lucky_purchase`). *Giải pháp:* Whitelist enum validation trên mobile, fallback gracefully nếu type khác `flash_sale`.
