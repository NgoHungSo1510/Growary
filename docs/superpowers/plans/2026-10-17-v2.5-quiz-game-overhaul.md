### Hằng số gameplay (đã chốt — chỉnh ở MỘT chỗ: `backend/src/constants.ts`)

| Hằng số | Giá trị | Ý nghĩa |
|---|---|---|
| `QUIZ_QUESTION_TIME_SEC` | 30 | Thời gian mỗi câu (khớp timer mobile hiện tại) |
| `QUIZ_SPEED_THRESHOLD_SEC` | 10 | Trả lời đúng trong ≤ 10s = "thần tốc" |
| `QUIZ_SPEED_BONUS_COINS` | 10 | Xu thưởng mỗi câu thần tốc |
| `QUIZ_STREAK_MULTIPLIERS` | `{2: 0.1, 3: 0.2, 4: 0.3, 5: 0.5}` (≥5 dùng 0.5) | Bonus = `floor(rewardPerCorrect × hệ số streak sau câu đó)` |
| `QUIZ_XP_PER_CORRECT` | 10 | EXP mỗi câu đúng |
| `QUIZ_PERFECT_XP_BONUS` | 20 | EXP thêm khi Perfect |
| `QUIZ_PERFECT_TICKETS` | 1 | Vé gacha khi Perfect |
| `QUIZ_TRANSITION_GRACE_SEC` | 5 | Bù countdown 3s / reveal 3s + mạng (dùng chống hack thời gian) |
| `QUIZ_ATTEMPT_TTL_SEC_PER_QUESTION` | 60 | Lượt hết hạn sau `questionsPerAttempt × 60s` (giữ hành vi cũ) |
| `QUIZ_LEADERBOARD_LIMIT` | 20 | Top N Bảng Vàng |

- **Perfect run** = `totalCorrect === answers.length && answers.length >= event.questionsPerAttempt && endReason === 'finished'` (không hardcode "5/5").
- **Điểm xếp hạng mỗi lượt** = `totalCorrect × 100 + speedAnswerCount × 10 + maxStreak × 50` (`speedAnswerCount` là **số câu** thần tốc, không phải số xu).
- **Bảng Vàng** tính theo **event** (không phải "tuần"): cộng `score` mọi lượt `completed` của user trong event; sắp xếp `totalScore desc, bestStreak desc, lastCompletedAt asc`; rank kiểu thi đấu (1, 2, 2, 4) = `1 + số user có totalScore lớn hơn`.

**Ví dụ chuẩn (dùng làm assertion trong test):**
- A — `rewardPerCorrect=50`, 5 câu đều đúng trong ≤10s: base 250, streak 0+5+10+15+25 = 55, speed 50 → **coinsEarned 355**, **xp 70**, **tickets 1**, **score 800**.
- B — đúng(5s), đúng(15s), sai, đúng(8s), timeout: base 150, streak 0+5+0+0+0 = 5, speed 20 → **coinsEarned 175**, **xp 30**, maxStreak 2, speedAnswerCount 2, **score 420**, không perfect.

Bất cứ khi nào `getUserQuizStatus`/`startOrResume` gặp lượt `in_progress` đã quá hạn → gọi `finalizeQuizAttempt(..., 'expired')` (câu chưa trả lời = sai, vẫn trả thưởng câu đúng, không perfect). Lượt `expired` **tính vào số lượt đã dùng** (sửa B2). Đếm lượt: `status ∈ {in_progress, completed}` trong cửa sổ cooldown (bỏ qua `abandoned` cũ).
- **Start:** có lượt `in_progress` còn hạn → trả về resume: `resumed:true`, `currentIndex = answeredCount`, set `lastAnsweredAt = now` và `speedBonusDisabledIndex = answeredCount` (câu đang dở có thể đã bị nhìn trước → không thưởng tốc độ). Không có → kiểm tra lượt; chọn topic: `isActive` + **số câu ≥ questionsPerAttempt** (đếm bằng 1 aggregate `$group` theo topic, không N+1), ưu tiên topic chưa chơi trong event; không có topic đủ câu → `AppError(409, 'Sự kiện chưa đủ câu hỏi, vui lòng quay lại sau', 'QUIZ_NOT_ENOUGH_QUESTIONS')` và **không tạo lượt**. Xáo câu bằng Fisher–Yates (không dùng `sort(() => Math.random() - 0.5)`). `QuizAttempt.create` ném lỗi `code === 11000` → đọc lại lượt `in_progress` và trả resume.
- **Submit:** đọc attempt (`_id`, `user`). Nếu đã `completed` → `409 QUIZ_ATTEMPT_CLOSED`. Tìm `idx` của `questionId`; không có → `400 QUIZ_QUESTION_NOT_IN_ATTEMPT`. Nếu `answers[idx].answeredAt` ≠ null → trả kết quả đã lưu với `alreadyAnswered:true` (HTTP 200). Nếu `idx !== answeredCount` → `409 QUIZ_OUT_OF_ORDER`. Tính timing với `anchor = lastAnsweredAt ?? startedAt`, chấm điểm bằng `scoreAnswer` (`speedBonusAllowed = idx !== speedBonusDisabledIndex`). Ghi bằng **một** `findOneAndUpdate` có điều kiện `{ _id, user, status:'in_progress', answeredCount: <giá trị đã đọc>, ['answers.'+idx+'.answeredAt']: null }` + `$set` field câu idx, `currentStreak`, `maxStreak`, `lastAnsweredAt` + `$inc: { answeredCount: 1 }`. Trả `null` → đọc lại: câu đó đã có `answeredAt` → trả stored `alreadyAnswered:true`; ngược lại `409 QUIZ_CONCURRENT_UPDATE`.
- **Finalize:** `endReason 'finished'` yêu cầu `answeredCount === answers.length`, nếu không → `409 QUIZ_NOT_FINISHED`. Nếu attempt đã `completed` → trả kết quả đã lưu, `alreadyCompleted:true`. Tính `summarizeAttempt`; chốt bằng `findOneAndUpdate({ _id, user, status:'in_progress' }, { $set: { status:'completed', completedAt, endReason, totalCorrect, baseCoins, ..., score } })`. Chỉ khi trả về document mới: `User.findById` → `user.coins += coinsEarned; user.gachaTickets += ticketsEarned; levelRewards = await processLevelUp(user, xpEarned); await user.save()` (cùng pattern với `planController`/`bossService`). `perfectBonus = isPerfect ? { tickets: 1, message: 'HOÀN HẢO! Nhận thêm 1 Vé Gacha!' } : null`; `levelUps = levelRewards.levelUps`.
