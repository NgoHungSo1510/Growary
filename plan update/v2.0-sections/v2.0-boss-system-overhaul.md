## 🎮 PHẦN 1: THIẾT KẾ GAMEPLAY MỚI

### 1.1 Cơ chế "Điểm Công" & "Đập Khóa"

```text
TRƯỚC (V1):
  Hoàn thành task → XP tự trừ HP boss → User không cần vào trang Boss

SAU (V2):
  Hoàn thành task → Tích "Điểm Công" vào BossRecord.attackPoints
                   → Coins bonus vẫn tích vào rương (Quỹ riêng - nhận 100%)
  
  User vào trang Nhân Vật → Thấy ⚡ X Điểm Công đang chờ
                       → Tự chọn lượng điểm muốn dùng: [25%] [50%] [75%] [ALL-IN]
                       → Nhấn "🔨 PHÁ KHÓA!"
                       → Mini-game 10s xuất hiện (random 1 trong 3 kiểu)
                       → Kết quả:
                          ✅ Hoàn thành → damage = Lượng điểm đã chọn × 2 (Critical!)
                          ⏱️ Bỏ qua     → damage = Lượng điểm đã chọn × 1 (Normal)
                       → Nếu damage > HP khóa còn lại ➡️ Trả lại (Refund) lượng Điểm Công chưa dùng hết vào ví.
                       → HP khóa giảm + animation đập khóa.
```

**Quy tắc:**
- Không giới hạn số lần tấn công/ngày — tấn công bất cứ khi nào có Điểm Công.
- Nút "Phá Khóa" chỉ hiện khi `attackPoints > 0`.
- Lượng damage dư (Overkill) sẽ được hoàn trả nguyên vẹn về `attackPoints`.

### 1.2 Mini-Game đập khóa (Random 1 trong 3 kiểu)

| # | Kiểu | Tên | Mô tả | Điều kiện Critical |
|---|------|-----|--------|-------------------|
| 🔴 | **Tap Speed** | "Búa Tạ" | Nhấn liên tục trong 5s | Đạt ≥20 tap |
| 🟡 | **Quick Quiz** | "Giải Mã" | 1 câu trắc nghiệm từ pool admin tạo, 10s | Trả lời đúng |
| 🔵 | **Reflex Hit** | "Điểm Yếu" | 3 vùng target xuất hiện ngẫu nhiên | Chạm đúng 3/3 |

**Logic chọn mini-game:**
- Nếu nhân vật có câu hỏi quiz (`miniGameQuestions.length > 0`) → random 1/3 kiểu.
- Nếu KHÔNG có câu hỏi quiz → random giữa "Tap Speed" và "Reflex Hit".

### 1.3 Mở khóa câu chuyện nhân vật & Bảng xếp hạng

```text
Ổ Khóa bị phá vỡ (HP = 0)
  → Cập nhật Bảng Xếp Hạng dựa trên totalDamageDealt:
      - Top 1: 100% thưởng gốc (Coins, XP, Vé)
      - Top 2: 75% thưởng gốc
      - Top 3: 50% thưởng gốc
      - Top 4+: 25% thưởng gốc
      * LƯU Ý: Bonus coins tích từ quest hàng ngày (accumulatedCoins) trả đủ 100% cho mọi người.
  
  → Tất cả user có đóng góp (totalDamageDealt > 0)
    → hasUnlockedStory = true
    → Hình ảnh nhân vật mất ổ khóa, hết mờ, hiện rõ 100%.
    → Lần đầu vào trang → Popup modal: Ảnh nhân vật + Cốt truyện.
```

### 1.4 Bộ sưu tập nhân vật & Hình phạt (Penalty)

```text
Admin tạo "BossCollection" (VD: "Bộ Truyện Doraemon")
  
User sưu tập = phá khóa nhân vật + có đóng góp
  → Nền bộ sưu tập màu xám. Khi đủ 100% nhân vật trong bộ → Viền bộ sưu tập sáng vàng.
  → User nhấn nút → Đọc "Truyện Tổng Kết" của bộ + Nhận bonusTickets vé quà.

Kết thúc bộ sưu tập (Khi nhân vật cuối cùng hết hạn):
  → Chạy CronJob: Trừ 50% tổng Điểm Công (attackPoints) của toàn bộ user để chống tích trữ.
```

### 3.2 [NEW] Attack Boss API (Hỗ trợ chọn % & Refund)
> `POST /events/boss/attack`

```typescript
// Body: { miniGameType, miniGameResult, usePercentage: 0.25 | 0.5 | 0.75 | 1.0 }

const pointsToUse = Math.floor(userRecord.attackPoints * usePercentage);
const multiplier = miniGameResult === 'critical' ? 2 : 1;
const potentialDamage = pointsToUse * multiplier;

let actualDamage = potentialDamage;
let refundPoints = 0;

if (potentialDamage > activeBoss.currentHp) {
    actualDamage = activeBoss.currentHp;
    const overkillDamage = potentialDamage - actualDamage;
    refundPoints = Math.floor(overkillDamage / multiplier); 
}

activeBoss.currentHp -= actualDamage;
userRecord.attackPoints = (userRecord.attackPoints - pointsToUse) + refundPoints;
userRecord.totalDamageDealt += actualDamage;
```

### 3.3 [MODIFY] bossService.ts — Bảng Xếp Hạng Thưởng
> Cập nhật `distributeBossRewards`:

> - Cộng nguyên vẹn `accumulatedCoins` cho user (không áp dụng hệ số).
> - Set `hasUnlockedStory = true` cho mọi record.
