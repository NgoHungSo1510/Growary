### Co che Chiet Khau khi Mua (VIP Discount)

**Ap dung ngay lap tuc** khi user nhan mua:
  actualPrice = Math.ceil(reward.pointCost * (1 - vipDiscountPercent / 100))

Hien thi mobile: ~~50,000~~ -> 48,500 (-3%) khi Tier 4

**Ket hop voi Flash Sale (khi co event):**
  finalPrice = Math.ceil(pointCost * (1 - flashDiscount/100) * (1 - vipDiscount/100))
  Vi du: item 50k, Flash -15%, VIP Tier4 -3%
  -> 50,000 x 0.85 x 0.97 = 41,225 coins
  -> Hien thi: ~~50,000~~ -> Sale: ~~42,500~~ -> VIP: 41,225

**Flash Sale KHONG ap dung cho:**
- Gacha spin cost
- Cac mua hang noi tai game khac (chi Shop rewards)

## 11. CRON JOBS

### shopEventJob.ts - Flash Sale Ngau Nhien

Schedule: 0 17 * * * (tuong duong 00:00 VN)

Logic:
1. Dem ShopEvent trong thang co isAutoGenerated=true -> neu da co -> SKIP
2. Math.random() < 0.10 (10%) -> tao FlashSale
3. discountPercent = random 5-20%
4. Duration = 24h tu luc tao
5. Chon ngau nhien thong diep tu MERCHANT_MESSAGES pool
6. Broadcast in-app notification cho tat ca user

### cashbackJob.ts - Cashback Cuoi Thang

Schedule: 0 17 1 * * (tuong duong 00:00 ngay 1 moi thang VN)

IDEMPOTENCY GUARD via lastCashbackProcessed (dinh dang YYYY-MM):
1. Query users: pendingCashback > 0 VA lastCashbackProcessed != thang truoc
2. Voi moi user:
   a. CONG pendingCashback vao coins TRUOC
   b. Tao Notification cashback summary
   c. Reset pendingCashback=0, monthlySpending=0
