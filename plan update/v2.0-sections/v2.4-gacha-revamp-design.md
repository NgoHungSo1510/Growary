# 🎰 Gacha System Revamp — Design Document

> **Ngày:** 2026-10-17
> **Tác giả:** Human Partner + AI (brainstorming session)
> **Trạng thái:** Chờ duyệt

---

## Intent & Why

Trang Gacha hiện tại có vòng quay kiểu pie chart SVG đơn giản, thiếu hiệu ứng hấp dẫn và không có cơ chế tạo động lực quay lại. User quay xong rồi bỏ, không có lý do để gắn bó.

**Mục tiêu:**
1. Biến trải nghiệm quay thành một moment thú vị kiểu CS:GO case opening — hồi hộp, cuốn hút
2. Tạo 2 trục motivation: **cày cấp** (tier system) + **FOMO** (event tuần có thời hạn)
3. Thêm social proof thông qua leaderboard và hall of fame
4. Kết nối kho rương thưởng (MysteryBox) vào gacha để mỗi tuần có quà mới săn được
5. Viết 3 agent skills để AI hiểu context khi làm việc trên các tính năng này

---

## Goals

- Thay vòng quay pie SVG bằng **CS:GO-style horizontal reel** — các item chạy ngang qua, chậm dần, dừng lại
- **Leaderboard toàn server** — bảng xếp hạng tuần ai quay trúng quà hiếm nhất, ai vượt tier
- **Lịch sử quay cải tiến** — filter theo rarity, theo ngày, UI đẹp hơn
- **Event tuần auto-reset** — mỗi thứ Hai 0h00, pool quà thay đổi, đếm ngược real-time
- **Rương thưởng random** — MysteryBox random gắn vào pool gacha theo tuần
- **3 agent skills** — gacha-system, gamification-design, growary-architecture

## Non-Goals

- Không thay đổi hệ thống tier/rarity hiện tại (vẫn giữ normal/rare/epic/legend)
- Không thêm tính năng PvP hoặc multiplayer trực tiếp
- Không thay đổi cách earn gacha tickets (giữ nguyên flow hiện tại)

## Anti-Goals (Nếu xảy ra = thất bại)

- Nếu animation CS:GO gây lag trên thiết bị yếu → thất bại
- Nếu leaderboard tạo áp lực tiêu cực thay vì khích lệ → thất bại
- Nếu user không biết event đang chạy hay đã kết thúc → thất bại

## Phần 1: CS:GO-Style Horizontal Reel

### 1.1 Cơ chế hoạt động

Thay [LuckyWheel.tsx](file:///d:/Downloads/SE%20Project/Growary/mobile/src/components/LuckyWheel.tsx) (vòng tròn SVG) bằng `GachaReel` (thanh cuốn ngang):

```
┌─────────────────────────────────────┐
│ ◄ [item] [item] [▼ITEM▼] [item] [item] ► │
│           ↑ kim chỉ (center)              │
└─────────────────────────────────────┘
```

- Hiển thị ~5-7 item cùng lúc trên thanh
- Khi ấn SPIN, các item chạy nhanh sang trái
- Chậm dần (easing: `Easing.out(Easing.cubic)`)
- Dừng lại ở item trúng, đúng giữa kim chỉ
- Item trúng được highlight (glow effect + scale up nhẹ)

### 1.2 Visual Design

- **Thanh reel**: background glassmorphism blur, bo góc, shadow
- **Mỗi item card**: hiển thị icon + tên + viền màu rarity
  - Normal: viền xanh lá `#71B93F`
  - Rare: viền xanh dương `#2D9CDB`
  - Epic: viền tím `#9B51E0`
  - Legend: viền vàng gold `#F2C94C` + shimmer animation
- **Kim chỉ**: ở giữa thanh reel, hình tam giác ▼ phía trên + ▲ phía dưới
- **Khi dừng**: item trúng phát sáng, nếu rarity ≥ epic thì thêm particle effect
- **Âm thanh (optional future)**: tick-tick-tick chậm dần

### 1.3 Technical Implementation

**Thay đổi file:**
- ❌ Xóa: [LuckyWheel.tsx](file:///d:/Downloads/SE%20Project/Growary/mobile/src/components/LuckyWheel.tsx) (320 dòng)
- ✅ Tạo mới: `mobile/src/components/gacha/GachaReel.tsx`
- ✅ Sửa: [GachaEventScreen.tsx](file:///d:/Downloads/SE%20Project/Growary/mobile/src/screens/GachaEventScreen.tsx) — import GachaReel thay LuckyWheel

**Props cho GachaReel:**
```typescript
interface GachaReelProps {
    items: IGachaItem[];
    onSpinRequest: () => Promise<IGachaItem | null>;
    onSpinComplete: (item: IGachaItem) => void;
    width?: number; // chiều rộng thanh reel
    itemWidth?: number; // chiều rộng mỗi card item
}
```

**Kỹ thuật animation:**
- Dùng `Animated.View` với `translateX` (performant hơn ScrollView)
- Tạo danh sách item lặp lại nhiều lần (vd: x20) để tạo cảm giác cuộn dài
- Item trúng nằm ở vị trí đã tính toán sẵn trong dãy lặp
- Duration: ~4-5 giây, easing `Easing.bezier(0.1, 0.7, 0.1, 1)` (sharp fast start, very slow end)

## Phần 2: Hệ Thống Event Tuần + Countdown

### 2.1 Cơ chế

- Mỗi tuần từ **thứ Hai 0h00 → Chủ Nhật 23:59** là 1 event cycle
- Pool quà thay đổi mỗi tuần (admin set hoặc auto-rotate từ tổng pool)
- Rương thưởng (MysteryBox) được gắn random vào pool mỗi tuần
- Countdown hiển thị real-time trên trang gacha

### 2.2 Backend Changes

**Model mới:** `backend/src/models/GachaWeeklyEvent.ts`

```typescript
interface IGachaWeeklyEvent {
    _id: ObjectId;
    weekStart: Date;       // Thứ Hai 0h00
    weekEnd: Date;         // Chủ Nhật 23:59:59
    featuredItems: ObjectId[];  // Ref GachaItem — item đặc biệt tuần này
    featuredBoxes: ObjectId[];  // Ref MysteryBox — rương random gắn vào
    autoGeneratedItems: ObjectId[]; // GachaItem tự tạo từ MysteryBox
    isActive: boolean;
    createdAt: Date;
}
```

**API mới:**

| Method | Route | Mô tả |
|--------|-------|--------|
| GET | `/api/gacha/weekly-event` | Lấy event tuần hiện tại + countdown |
| GET | `/api/gacha/leaderboard` | Top 10 user tuần này |
| POST | `/api/admin/gacha/weekly-event` | Admin tạo/edit event tuần |

**Weekly rotation logic** (trong `backend/src/services/gachaService.ts`):
1. Mỗi khi call `GET /weekly-event`, check nếu chưa có event cho tuần hiện tại → auto-create
2. Random chọn 1-2 MysteryBox active từ kho
3. Tạo GachaItem tạm cho mỗi MysteryBox (type: 'item', rewardId trỏ đến reward tương ứng)
4. Set `isActive: true` cho item tuần này, deactivate item tuần trước

### 2.3 Frontend Changes

**Timer badge** trong [GachaEventScreen.tsx](file:///d:/Downloads/SE%20Project/Growary/mobile/src/screens/GachaEventScreen.tsx):
- Thay chuỗi tĩnh `"Event Ends in 12h 30m"` bằng countdown thật
- Tính từ `weekEnd - Date.now()`, hiển thị `DDd HHh MMm`
- Khi ≤ 1 giờ: badge chuyển đỏ, nhấp nháy nhẹ (urgency effect)

**Weekly featured section**: hiển thị các quà đặc biệt tuần này (bao gồm rương random) bên dưới reel

## Phần 3: Leaderboard / Bảng Vinh Danh

### 3.1 Scoring System

Mỗi lần quay trúng, user được cộng điểm theo rarity:

| Rarity | Điểm |
|--------|------|
| Normal | 1 |
| Rare | 5 |
| Epic | 20 |
| Legend | 100 |

Vượt tier = +50 điểm bonus.

### 3.2 Backend

**Model mới:** `backend/src/models/GachaLeaderboard.ts`

```typescript
interface IGachaLeaderboard {
    _id: ObjectId;
    userId: ObjectId;         // Ref User
    weekStart: Date;          // Thứ Hai 0h00 của tuần đó
    totalScore: number;
    spinCount: number;
    bestRarity: 'normal' | 'rare' | 'epic' | 'legend';
    tierUps: number;          // số lần vượt tier trong tuần
    updatedAt: Date;
}
```

**Index:** `{ weekStart: 1, totalScore: -1 }` để query top nhanh.

**Logic update:** Trong [gachaController.spinGacha](file:///d:/Downloads/SE%20Project/Growary/backend/src/controllers/gachaController.ts#L46-L104):
- Sau khi spin thành công → findOneAndUpdate `GachaLeaderboard`
- Upsert: tìm record cho (userId, weekStart), cộng điểm, tăng spinCount
- Cập nhật bestRarity nếu rarity mới cao hơn

### 3.3 Frontend

**Component mới:** `mobile/src/components/gacha/GachaLeaderboard.tsx`

Đặt trên trang GachaEventScreen, dưới reel:
- **Tab "Tuần Này"**: Top 10 user, hiển thị avatar + username + score + best rarity badge
- **Tab "Vinh Danh"**: User đứng #1 tuần trước, user vượt tier cao nhất tuần trước
- Highlight bản thân nếu nằm trong bảng (viền vàng)
- Nếu chưa lọt top 10: hiển thị thứ hạng riêng phía dưới ("Bạn: #42 — 15 điểm")

## Phần 5: Rương Thưởng (MysteryBox) Gắn Vào Gacha

### 5.1 Cơ chế

Hệ thống [MysteryBox](file:///d:/Downloads/SE%20Project/Growary/backend/src/models/MysteryBox.ts) đã có sẵn:
- Admin tạo mystery boxes với rewards bên trong
- Mỗi box có rarity, probability config

**Mỗi tuần:**
1. Cron/startup check → random chọn 1-2 MysteryBox active
2. Tạo GachaItem tạm: `{ name: box.name, type: 'item', rarity: map(box.rarity), probability: tuỳ config }`
3. Link qua `rewardId` hoặc thêm field `mysteryBoxId` trên GachaItem
4. Item này chỉ active trong tuần hiện tại
5. Khi hết tuần → deactivate

### 5.2 Khi User Trúng Rương

Giữ flow hiện tại trong [spinGacha](file:///d:/Downloads/SE%20Project/Growary/backend/src/controllers/gachaController.ts#L75-L83):
- Trúng item type 'item' → tạo Voucher
- User nhận voucher → đổi thưởng qua flow Reward/Voucher sẵn có

> **Builder's call:** Không thêm auto-open mystery box. Giữ flow voucher đơn giản.
