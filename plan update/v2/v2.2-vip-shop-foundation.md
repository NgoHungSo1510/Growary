### [MODIFY] backend/src/routes/rewards.ts — Purchase Route

Sua POST /:rewardId/purchase:

`	ypescript
// --- MOI (thay cho logic cu) ---

// 1. Tinh gia thuc te sau VIP discount
const actualPrice = applyVipDiscount(reward.pointCost, user.vipTier);

// 2. Tru coins, cap nhat spending
user.coins -= actualPrice;
user.monthlySpending += actualPrice;
user.pendingCashback += calcCashback(actualPrice, user.vipTier);
user.totalCoinsSpent += actualPrice;

// 3. Kiem tra len tier
const newTier = calcVipTier(user.totalCoinsSpent);
if (newTier > user.vipTier) {
  user.vipTier = newTier;
  if (!user.claimedVipTiers.includes(newTier)) {
    // Grant qua rank-up
    user.coins += RANK_UP_GIFTS[newTier].coins;
    // grant gacha tickets (theo bang o muc 1)
    user.claimedVipTiers.push(newTier);
    // Tao notification rank-up (xem muc 4b)
  }
}

// Response tra them: newVipTier?, rankUpReward?
// { voucher, remainingCoins, newVipTier?, rankUpReward? }
`

  [+N] Gacha Ticket

### [NEW] backend/src/jobs/cashbackJob.ts

`
Schedule: 0 17 1 * *  (= 00:00 ngay 1 moi thang, gio VN)

Logic (theo thu tu, KHONG thay doi):
1. Query users: pendingCashback > 0
              AND lastCashbackProcessed != 'YYYY-MM' (thang vua qua)
2. Voi moi user — atomic findByIdAndUpdate:
   a. CONG pendingCashback vao coins TRUOC
   b. Tao Notification "Sao Ke Thang"
   c. Reset: pendingCashback=0, monthlySpending=0
   d. Set: lastCashbackProcessed = 'YYYY-MM' (thang vua qua)
3. An toan:
   - Chay 2 lan: user da co lastCashbackProcessed -> bi loc ra -> SAFE
   - Crash giua chung: user chua set -> xu ly lai lan sau -> SAFE
   - Thu tu CONG TRUOC ROI MOI RESET -> khong mat data
`

Notification cashback cuoi thang:
`
Sao Ke Thang [Thang/Nam]
Hang: [Ten Tier]
Tong chi thang: [N] coins
Cashback [X]%: [M] coins
-> [M] coins da duoc them vao tui!
[Xem Chi Tiet] [Dong]
`
