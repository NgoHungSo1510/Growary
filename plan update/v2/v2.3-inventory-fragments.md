## 3. API ROUTES — User

Them vao backend/src/routes/rewards.ts:

`
GET /rewards/inventory
    -> Tra UserInventory cua user hien tai
    -> Kem metadata tung itemType (displayName, color, canExchange)

POST /rewards/inventory/open-box
     Body: { itemType: 'mystery_box_boss' }
     Logic:
       1. Kiem tra user.inventory co itemType, quantity >= 1
       2. Tru 1 box khoi inventory (atomic)
       3. Random reward theo MysteryBox.rewards (weighted random theo probability)
       4. Cong reward vao:
          - coins -> user.coins += amount
          - gacha_ticket -> grant 1 ticket
          - fragment -> inventory[fragmentType] += amount
       5. Response: { reward: { type, itemType?, amount, displayName } }

POST /rewards/inventory/exchange-fragment
     Body: { fragmentType: 'frag_3k' }
     Logic:
       1. Kiem tra quantity >= 10 (neu khong du: 400 "Can du 10 manh")
       2. Tru 10 manh khoi inventory (atomic)
       3. Tao Voucher moi:
          code = 'FRAG-' + random 8 chars
          status = 'active'
          frag_freeship -> hasFreeShip = true
          frag_Xk      -> discountAmount = X * 1000
          fragmentType = fragmentType
       4. Response: { voucher }
`

## 4. API ROUTES — Admin

Them vao backend/src/routes/admin.ts:

`
GET    /admin/mystery-boxes
       -> List tat ca Mystery Box types (name, rarity, isActive, so rewards)

POST   /admin/mystery-boxes
       Body: { name, description, itemType, rarity, rewards[] }
       Validate: sum(rewards.probability) == 100

PUT    /admin/mystery-boxes/:id
       -> Sua ten, mo ta, rewards, isActive toggle
       Validate lai probability = 100

DELETE /admin/mystery-boxes/:id
       -> Xoa (chi khi chua assign cho user nao)

GET    /admin/user-inventory/:userId
       -> Xem toan bo kho cua 1 user cu the

POST   /admin/inventory/grant
       Body: { userId, itemType, quantity, reason }
       -> Them item thang vao UserInventory
       -> Ghi log: { adminId, userId, itemType, quantity, reason, createdAt }
       -> Response: { updatedInventory }
`
