// 1. Detect active Flash Sale
const activeEvent = await ShopEvent.findOne({
  type: 'flash_sale',
  isActive: true,
  endDate: { $gt: new Date() },   // NOTE: $gt la MongoDB operator, dung ngoac nhu nay

// 2. Voi moi reward: tinh displayPrice sau VIP discount
const vipDiscount = getVipConfig(user.vipTier).discountPercent;
const displayPrice = applyVipDiscount(reward.pointCost, user.vipTier);

// 3. Neu co Flash Sale: tinh them salePrice
let salePrice = displayPrice;
if (activeEvent && activeEvent.discountPercent > 0) {
  salePrice = Math.ceil(displayPrice * (1 - activeEvent.discountPercent / 100));

## 4. CRON JOB — FLASH SALE RANDOM

### [NEW] backend/src/jobs/shopEventJob.ts

```
Schedule: 0 17 * * *  (= 00:00 VN moi ngay)

Logic:
1. Dem ShopEvent trong thang nay co isAutoGenerated = true
   -> Neu da co -> SKIP (moi thang chi tao 1 auto event)

2. Math.random() < 0.10  (10% xac suat)
   -> Tao Flash Sale moi:
      discountPercent = Math.floor(Math.random() * 16) + 5  // 5-20%
      startDate = now
      endDate = now + 24h
      isAutoGenerated = true
      title / description = random tu MERCHANT_MESSAGES pool

3. Broadcast in-app notification cho tat ca user
```

## 5. ADMIN API

Them vao backend/src/routes/admin.ts:

```
GET    /admin/shop-events
       -> List tat ca ShopEvent (filter: active/inactive/all)
       -> Bao gom isAutoGenerated flag de hien badge "Auto"

POST   /admin/shop-events
       Body: { title, description, type, discountPercent, targetRewards[], startDate, endDate }
       -> Admin tao event thu cong
       -> Set isAutoGenerated = false, createdBy = adminId

PUT    /admin/shop-events/:id
       -> toggle isActive
       -> update discountPercent, targetRewards, endDate

DELETE /admin/shop-events/:id
       -> Chi xoa duoc event chua bat dau (startDate > now)

GET    /admin/special-items-config
       -> List tat ca Product->Fragment mappings

POST   /admin/special-items-config
       Body: { rewardId, fragmentType }

PUT    /admin/special-items-config/:id
       Body: { isActive?, addedToBoxPool? }

DELETE /admin/special-items-config/:id
```
