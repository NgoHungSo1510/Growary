### Quy tắc bất khả xâm phạm:
1. **Shared Types First + Mirror Sync:** Mọi thay đổi kiểu dữ liệu phải sửa ở `shared/types/*.ts` trước, sau đó copy y hệt sang `backend/src/shared/*.ts` và kiểm tra bằng `git diff --no-index`.
2. **Atomic Database Operations:** Tuyệt đối không đọc `user.coins` / `reward.stock` ra biến nhớ rồi cộng trừ và `.save()`. Bắt buộc dùng `findOneAndUpdate` với điều kiện `$gte` / `$gt` và toán tử `$inc`.
3. **Zero `any` & Strict Validation:** Cấm `: any`, `as any`, `@ts-ignore`. Mọi route `POST`/`PUT`/`PATCH` phải qua middleware `validate(zodSchema)`.
4. **Multi-Repo Commit Order:** Luôn commit repo con `backend/` trước (`git -C backend commit ...`), sau đó mới commit repo gốc `Growary/`.
